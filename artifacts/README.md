# Artifacts (automated test outputs)

This directory stores ephemeral outputs created by automated tests and verification scripts (for example, screenshots generated by Playwright).

Purpose
- Store temporary test artifacts (screenshots, logs, etc.) for local debugging and CI job uploads.

Regeneration
- Screenshots are generated by the Playwright test at `scripts/playwright/test_dashboard.py`.
- To regenerate the screenshots locally:

```fish
# Start the Streamlit app (in background)
cd /home/chuck/Projects/cycle-navigator-dashboard
/home/chuck/Projects/cycle-navigator-dashboard/venv/bin/streamlit run stock_dashboard.py > /tmp/streamlit.log 2>&1 &

# Run the Playwright verification script (headed)
/home/chuck/Projects/cycle-navigator-dashboard/venv/bin/python /home/chuck/Projects/cycle-navigator-dashboard/scripts/playwright/test_dashboard.py
```

Recommendations
- Do not commit the entire `artifacts/` folder into Git. Add `artifacts/` to `.gitignore` and keep artifacts locally or upload them as CI build artifacts when needed.
- If you want to keep a canonical screenshot for documentation, move that single file into `docs/screenshots/` and commit only that file.

CI Integration
- In CI pipelines, generate these artifacts during the test stage and upload them as pipeline artifacts for later inspection.

Cleanup
- Remove old artifacts with `rm -rf artifacts/*`.

If you want, I can also add `artifacts/` to `.gitignore` for you.
