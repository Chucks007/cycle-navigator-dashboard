# Cycle Navigator - Web Frontend

This is the Next.js frontend for the Cycle Navigator Dashboard.

## Getting Started

### Prerequisites

Ensure the backend is running on `http://localhost:8000` (or configure `NEXT_PUBLIC_API_URL` / `BACKEND_URL`).

### running Locally

First, install dependencies:

```bash
npm install
# or
yarn install
```

Then run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Docker

This directory contains a `Dockerfile` for building the production image.
Refer to the root `docker-compose.yml` for orchestration.
